# 템플릿 개선 — 2026-10-28~29

## 상태

요청된 여섯 항목의 구현과 로컬 자동 검증을 완료했다. Android 실기기 한 대의 기본 흐름도 확인했으며, 방향 복귀 후속 확인과 원격 CI는 미검증 범위에 남긴다.

## 완료한 작업

1. 저장 재시도: 정상 읽기 뒤 쓰기 실패만 자동·수동 재시도하며 최신 메모리 진행 상태를 보존한다. 읽기 실패·손상·미래 버전 보호는 유지한다.
2. 전체화면 조작: 기존 버튼을 전체화면 영역에 포함해 시작·일시정지·재개·메뉴·재시작이 가능하다.
3. 브라우저 검증: Chromium·Firefox·WebKit 공통 E2E와 CI 설치를 추가하고 Chromium CDP touch를 별도 helper로 분리했다.
4. 움직임 줄이기: 설정 변경·초기화를 메뉴 tween과 CSS에 즉시 반영하며 장면 shutdown에서 설정 구독을 해제한다.
5. E2E 실행 격리: 개발/배포 포트·출력을 분리하고 배포 검사는 전용 빌드를 직접 생성한다. 기존 서버를 재사용하지 않는다. 기존 4173 포트 충돌로 이 작업을 앞당겨 적용했다.
6. 의존성 경계: ESLint가 공통 모듈에서 게임 모듈로 향하는 정적·동적·타입 import와 re-export를 차단한다.

## 검증 결과

- `npm run check`: 단위 67개, 린트·포맷·타입·빌드 통과.
- 개발/배포 E2E: 각각 70개 통과, 8개 의도적 skip.
- standalone E2E: 2개 통과.
- 전체화면 screenshot과 휴대폰 가로 에뮬레이션의 버튼 배치·일시정지·재시작 확인.
- Samsung SM-F966N / Android 17 / Chrome에서 메뉴·게임·전체화면 조작과 새로고침 후 저장 복원을 확인했다. 전체화면 종료 후 가로 방향 유지가 관찰되어 자동 회전을 켠 상태에서 추가 확인이 필요하다.
- 회귀 검사와 환경별 상세 결과는 [검증 기록](template/VALIDATION.md)에 있다.

## 미검증 범위

다른 Android 기기와 실제 iPhone·Safari·GPU·청음·장시간 플레이, HTTPS 배포 환경에서의 실기기 동작, 실제 광고·계정 동기화와 원격 CI 실행. 다음 기기 검증은 [개발 안내의 목록](DEVELOPMENT.md#검증)에 따라 기기·OS·브라우저·결과를 기록한다.
